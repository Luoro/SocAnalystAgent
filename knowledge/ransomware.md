# Ransomware Response

## Initial Response

When ransomware is detected, the affected endpoint should be isolated from the network.

The security team should preserve forensic evidence before making major changes to the system.

The affected user account should be reviewed for signs of compromise.

## Investigation

The SOC analyst should collect EDR telemetry and identify suspicious processes.

The analyst should investigate lateral movement and determine whether additional endpoints are affected.

The incident timeline should be reconstructed using available logs.

## Recovery

Systems should only be restored after the threat has been contained.

Affected credentials should be reset when compromise is suspected.

Backups should be validated before restoration.
