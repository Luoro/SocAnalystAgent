# Phishing Response

## Initial Response

When a phishing email is reported, the SOC analyst should collect the original email and its headers.

The analyst should identify the sender, URLs, domains, and attachments involved.

The message should be removed from affected mailboxes when necessary.

## Investigation

URLs and domains should be analyzed using available threat intelligence sources.

Attachments should be analyzed in a controlled environment.

The analyst should determine whether users interacted with the malicious content.

## Recovery

Compromised credentials should be reset.

Affected users should be notified.

Indicators of compromise should be added to appropriate security controls.
